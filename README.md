# Sari Sari 

  Is a Inventory Stock mobile app that helps small store owners keep track of their everyday products. You can add items, update stock counts as you sell or restock, and record prices.
  
## Features 

- **Overview** – a quick-start banner and "Your shelves", a per-category summary of saved products and units.
- **Inventory** – only the products the store has added, with category tabs, search, stock filter, sort, and grid/list views. New products are added through **Add item**, which opens the catalog picker.
- **Categories** – the four shelves (Pantry, Snacks, Beverages, Household Supplies) with catalog photos and how many of each are in inventory.
- **Getting started** and **Install app** dialogs (the Install button sits in the top bar).

## How to Install and Run

### Prerequisites
- [Node.js](https://nodejs.org/) (version 18 or newer) and npm
- [Git](https://git-scm.com/)
- A web browser (Chrome, Edge, or Firefox)

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/chrrymbalangatan/Small-Store-Inventory.git
   cd Small-Store-Inventory
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```
### Run the App Locally

```bash
npm install -g netlify-cli
netlify dev
```
### Install on a Phone
Sari Sari is a mobile-friendly app. Open it in your phone's browser and tap the **Install** button in the top bar to add it to your home screen.

**Link : https://small-store-inventory-app.netlify.app**
